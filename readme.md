This sample repository provides the GitHub issue templates your team must use.
Copy the entire .github/ISSUE_TEMPLATE folder, including all template files, into your team repository.

The folder contains scripts that automatically populate the appropriate issue template for a Value, Epic, Feature, User Story, or Task.

```text
.github/
└── ISSUE_TEMPLATE/
    ├── value.yml
    ├── epic.yml
    ├── feature.yml
    ├── user-story.yml
    └── task.yml
```
